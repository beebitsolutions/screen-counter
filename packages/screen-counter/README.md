# @beebit/screen-counter

> WIP — see the planning docs for scope and status.

Count screens (routes + modals) in a Next.js project. Two modes:

- **CLI**: generate an auditable screen-count report (for budgeting).
- **Plugin + badge**: live `X/Y screens` indicator in dev and demos.

## Development

From the monorepo root:

```bash
pnpm install
pnpm dev:package   # tsup watch
```

## Status

Skeleton only. Implementation is tracked in the project plan (Epics 2–7).
